# sdkwork-whatseek-h5-commons

Shared leaf components and utilities for the WhatSeek H5 app: `ScreenState` (the five mandatory UI states — loading / empty / error / permission-denied / success), `Avatar`, `ListRow`, `SectionHeader`, and the `cx` class helper.

Follows `../../../../../sdkwork-specs/APP_MOBILE_REACT_UI_SPEC.md` and `FRONTEND_CODE_SPEC.md`. Components are presentation-only: no data fetching, no client construction, no routing assumptions.
